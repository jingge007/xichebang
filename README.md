# 喜车邦自助洗车系统

## 项目简介

喜车邦自助洗车系统是一个基于Vue.js的前端项目，用于展示自助洗车服务的相关信息，包括新会员注册流程、自助洗车使用说明、会员注册协议和常见问题解答等内容。

## 技术栈

- **前端框架**：Vue 2.6.11
- **路由管理**：Vue Router 3.6.5
- **CSS预处理器**：Less 3.0.4
- **海报生成**：html2canvas 1.4.1
- **构建工具**：Vue CLI 4.5.19
- **代码规范**：ESLint 6.7.2

## 功能特点

### 1. 主页导航
- 提供系统标题和导航按钮
- 支持页面切换功能，可导航到注册流程、使用说明、会员协议和FAQ页面
- 现代化的UI设计，响应式布局，适配不同屏幕尺寸

### 2. 新会员注册流程页面
- 展示注册的6个步骤，包括关注公众号、会员注册、信息填写、充值、获取洗车码等
- 支持洗车码切换功能，可选择不同的洗车码
- 提供海报生成功能，可将注册流程生成为图片并下载
- 详细的图文说明，便于用户理解注册流程

### 3. 自助洗车使用说明页面
- 展示自助洗车的7个使用步骤，包括扫码、冲水、泡沫、吸尘、洗手、结算等
- 提供温馨提示，包括计费规则、充值说明、赠送金规则等
- 支持洗车二维码和微信二维码的切换功能
- 提供海报生成功能，可将使用说明生成为图片并下载

### 4. 会员注册协议页面
- 详细的会员注册协议内容，包括10个章节
- 清晰的排版和层级结构，便于用户阅读
- 响应式设计，确保在移动端正常显示

### 5. 常见问题解答页面
- 提供6个常见问题及其答案
- 简洁明了的问题和答案布局
- 响应式设计，确保在移动端正常显示

## 部署说明

### Vercel部署
1. 确保项目已推送到GitHub仓库
2. 登录Vercel账户
3. 导入GitHub仓库
4. 选择默认配置，点击部署
5. 等待部署完成，获取部署URL

### 其他部署方式
- 可以将`npm run build`生成的`dist`目录部署到任何静态网站托管服务
- 支持部署到GitHub Pages、Netlify、AWS S3等服务

## 技术实现亮点

1. **组件化开发**：采用Vue组件化开发方式，将不同功能模块封装为独立组件，提高代码复用性和可维护性

2. **路由管理**：使用Vue Router实现页面导航，支持浏览器历史记录和前进后退功能

3. **响应式设计**：使用CSS媒体查询和弹性布局，确保在桌面端和移动端都有良好的显示效果

4. **海报生成功能**：集成html2canvas库，实现页面内容转图片功能，方便用户保存和分享

5. **现代化UI设计**：采用现代化的配色方案和布局设计，提供良好的用户体验

6. **代码规范**：使用ESLint确保代码质量和一致性

## 注意事项

- 项目使用Vue 2.6.11，已达到EOL（生命周期结束），建议后续考虑升级到Vue 3
- 项目依赖的部分库版本较旧，可能存在安全隐患，建议定期更新依赖
- 部署时请确保使用npm官方仓库，避免从私有仓库下载依赖导致的身份验证问题
